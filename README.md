# Вариант 19. Cклад химикаток

Курсовой проект по ПМ.02. Заполните карточку варианта.

## Входные данные
(MQ2 (пары, 0–100 %)	NTC (температура)	US (расстояние до уровня жидкости)	реле (вентиляция)	синий, 10 мА / 3 с	пары > 30 %)

## Ссылка на проект Wokwi
([Simulate this project on https://wokwi.com](https://wokwi.com/projects/478294872694667265)
)

## Файлы
(- `sim/` — модель схемы в Wokwi, файл diagram.json.
- `firmware/` — программа Arduino для опроса датчиков и управления реле.
- `db/schema.sql` — создание таблиц базы данных.
- `db/variant.db` — база SQLite с показаниями и событиями.
- `db/queries.sql` — три запроса для просмотра и анализа данных.
- `db/load.sql` — SQL-команды загрузки, сформированные Node-RED.
- `nodered/flow.json` — экспорт потока Node-RED.
- `data/log.txt` — лог показаний из Wokwi.
- `data/log_fault.txt` — тестовый лог с недопустимым показанием.
- `docs/` — схемы, перечень элементов и скриншоты проверок.
- `README.md` — описание проекта и порядок запуска.)

## Порядок запуска
1. Запустить `start-nodered.bat`, открыть http://localhost:1880, импортировать `nodered/flow.json`, нажать Deploy.
2. Запустить симуляцию в Wokwi, скопировать вывод Serial Monitor в `data/log.txt`, сохранить файл.
3. Проверить данные: `sqlite3 db\variant.db ".read db\queries.sql"`.
